# NOVA Market BI

End-to-End Retail Business Intelligence and Data Warehouse Project.

## Project Goal

Build a professional BI solution using real-world retail transaction data and a structured business intelligence architecture.

## Data Source

Brazilian E-Commerce Public Dataset by Olist.

## Technology Stack

- SQL Server
- Python
- SSIS
- Power BI
- Git / GitHub

## Architecture

Olist Real Data
→ Raw / Staging
→ Conformed Layer
→ Data Warehouse
→ Power BI
